1. **HR-интеграция:** `applyEndpoint` пуст → карточка сохраняется только в localStorage.
2. **Персональные данные:** ФИО/дата рождения/контакты в localStorage без шифрования; нужна продуктовая политика хранения/удаления.
3. **PDF:** страница-картинка (текст не выделяется), кириллица визуально корректна.
4. **Ручные проверки:** установка PWA через UI (Chrome/Edge, iOS), системный back-gesture, экранная клавиатура, VoiceOver/TalkBack, анимации на слабых устройствах.
5. **Демо-контент:** вакансии/зарплаты/приз/промокоды демонстрационные; юридические формулировки согласовать с брендом.
6. **Аналитика/UTM** не подключены — вне рамок QA.
